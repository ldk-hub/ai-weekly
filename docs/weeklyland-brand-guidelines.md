# 위클리랜드 (WeeklyLand) 브랜드 가이드라인

## 1. 브랜드 정체성 (Brand Identity)

- **브랜드명**: 위클리랜드 (WeeklyLand) — AI위클리 3D 인터랙티브 테마파크
- **핵심 슬로건**: *"AI 트렌드가 살아 숨 쉬는 3D 테마파크 — 관리자는 세계를 설계하고, 방문객은 하늘을 질주한다."*
- **이중 무드 (Dual Atmosphere)**:
  - **Sunlit Daylight**: 따뜻한 사암 산책로, 테라코타 강철 레일, 브라스 골드 장식, 에메랄드 수목이 어우러진 클래식 플래닛코스터 미니어처 감성.
  - **Magical Night Bloom**: 깊은 미드나잇 블루 밤하늘 아래 페어리라이트, 관람차 LED, 코스터 LSM 청록 스트립, `UnrealBloomPass`와 3막 야간 불꽃축제가 펼쳐지는 야간 환상 무드.

## 3. 타이포그래피 (Typography)

- **Display / Headings**: `Newsreader`, serif — 테마파크 간판·파빌리온 타이틀의 클래식한 품격
- **UI Body / Labels**: `Pretendard`, `Inter`, system-ui, sans-serif — 고가독성 한국어/영문 HUD 제어
- **Telemetry / Coordinates**: `JetBrains Mono`, monospace (`tabular-nums`) — 속도(km/h), G-Force, EFN 지수, 3D 좌표

## 4. 보이스 & 네이밍 규칙 (Voice & Naming)

- **관리자 모드 (Architect Mode)**: 정밀하고 명료한 설계 용어 사용 (`노드 연장`, `뱅킹 각도`, `지형 브러시`, `공원 배포`).
- **방문객 모드 (Guest Mode)**: 설렘과 몰입을 주는 테마파크 안내 톤 (`앞좌석 탑승`, `드론 조망`, `불꽃축제 카운트다운`).
- **어트랙션 네이밍**: AI위클리 데이터 도메인 + 클래식 테마파크 어트랙션 결합 (`스타보드 하이퍼 코스터`, `프론티어 벤치마크 드롭`, `위클리 대관람차`, `클로드 그랜드 회전목마`).
